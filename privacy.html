Privacy policy

clip-flow is a personal tool used only by its owner to upload videos to the owner's own YouTube channels. It uses YouTube API Services.

What it accesses

  • Through the YouTube Data API it uploads videos (videos.insert) and reads basic information about the owner's own channels and uploads (channel name, video ID and processing status) to confirm each upload.
  • It does not access, collect or store data about any other YouTube user.

How data is stored and shared

  • OAuth sign-in tokens and upload results (video IDs) are stored only on the owner's own computer.
  • Nothing is sold or shared with any third party. Data is only sent to the platform it belongs to (YouTube).
  • No analytics, advertising, cookies or third-party tracking are used.

Deleting data and revoking access

  • Access can be revoked at any time from the Google security settings page.
  • When access is revoked, or on request to the contact below, the stored tokens and any stored YouTube API data are deleted within 7 days. API data that is not needed is not kept longer than 30 days.

Google and YouTube policies

clip-flow uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. clip-flow's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
